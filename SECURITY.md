# Security Policy

QuotaBar handles API tokens. If you find a vulnerability (token leakage,
credential mishandling, insecure storage, XSS-style content injection into the
menu), **do not open a public issue**.

Use GitHub's private channel: **Security tab → Report a vulnerability**
(private advisory, visible only to the maintainer), and you will get a response
within a few days.

Supported: the latest GitHub Release only. Older zips should be replaced, not patched.
