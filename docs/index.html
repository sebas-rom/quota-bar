Install

  1. Download QuotaBar.zip from releases.
  2. Drag QuotaBar.app to /Applications and launch.
  3. Toggle Launch at login in the ⋯ menu. No account setup needed if your keys are already on disk.

Missing your Go key?

Click Enter API key… in the menu, paste your opencode Personal API key — it's validated live and kept in your Mac's Keychain. Remove it anytime; your OpenCode/Codex credentials are never touched.

Privacy

Local-only. QuotaBar talks directly to the opencode.ai and ChatGPT usage endpoints with tokens already on your machine. No third-party servers, no analytics, no tracking. Security policy.

Contribute

All changes via pull request — main is protected and every change needs maintainer approval. Start with CONTRIBUTING.md.
